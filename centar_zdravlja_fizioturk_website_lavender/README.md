# Centar Zdravlja FizioTurk — website

Static bilingual website built with HTML and CSS only.

## Files
- `index.html` — Home / Početna
- `about.html` — About / O nama
- `services.html` — Services / Usluge
- `projects.html` — Projects / Projekti
- `contact.html` — Contact / Kontakt
- `styles.css` — shared styling

## Preview locally
Open `index.html` in a browser. All pages use relative links and share the same stylesheet.

## Before publishing
1. Replace placeholder address, phone, email and opening hours on `contact.html`.
2. Verify the service descriptions on `services.html` match the actual services offered.
3. Replace sample portfolio cards on `projects.html` with real projects, photos and descriptions (with appropriate permissions).
4. Replace the text-based `FT` logo placeholder with the official logo if available.
5. Update the copyright year if needed.

## Hosting
Upload all six files into the same folder on any static web host or your domain's web root. The pages will use paths such as `/about.html`, not subdomains.

No JavaScript, build step or framework is required.

## Colour theme
The visual theme is centred on the requested lavender `#ebc3f7`, paired with deeper plum accents, soft lilac surfaces and warm off-white backgrounds.
